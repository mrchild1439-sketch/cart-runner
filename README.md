# エネルギー保存トロッコ 🚃

「これ、力学的エネルギー保存する？保存しない？」を2択で答える物理クイズゲームです。

## 遊び方
- `index.html` をブラウザで開くだけで遊べます（外部ライブラリ不要）。
- トロッコに乗った一人称視点で線路を進みます。前方の分岐が近づいてくるので、制限時間 **20秒** 以内に「保存する／保存しない」の道を選びます。
- 正しい道 → 橋をわたってトンネルへ進み、次のステージへ。
- まちがった道 → 橋がくずれて谷へ落下し、ゲームオーバー。時間切れでも脱線して落下します。
- 全10ステージ（17問からランダム出題）。ゲームの終わりに、出題された問題を図つきで振り返る解説画面があります。

## 操作
- 画面下のボタン、画面の左右タップ、キーボードの ← → で選択
- 右上の 🔊 で効果音のON/OFF
